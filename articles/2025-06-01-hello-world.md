# Hello World! 🎉

这是我的第一篇博客文章，通过 **Agent Blog Publisher** 发布！

## 这是什么？

这是一个基于 Python 的轻量级博客系统，支持：

1. **Markdown 写作** - 用最流行的格式写文章
2. **自动发布** - 一键生成 HTML
3. **双线部署** - GitHub Pages + Cloudflare Pages

## 支持的内容类型

### 表格

| 功能 | 状态 | 说明 |
|------|------|------|
| Markdown 渲染 | ✅ | 支持 GFM 语法 |
| 图片处理 | ✅ | 自动压缩和复制 |
| 代码高亮 | ✅ | 支持多种语言 |
| 暗色模式 | ✅ | 跟随系统设置 |
